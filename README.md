# ClassBell / 课铃

一款纯本地的 macOS 菜单栏课铃：按时先响铃，再播报中文提醒，而且只把这次提醒送到你指定的蓝牙音箱。

其他音乐、视频和系统声音继续使用 Mac 的默认输出。目标音箱断线时，ClassBell 会跳过本次提醒，不会突然改用电脑扬声器。

## 适合谁

- 在家上课、写作业，需要固定学习与休息节奏的人。
- 小型教室、工作室或家庭，希望把铃声固定送到一台音箱的人。
- 不想注册账号、不想把日程和录音上传云端的人。

## 三分钟开始使用

1. 在 GitHub Releases 下载 `ClassBell-1.0.0-macOS.zip`。
2. 解压后将 `ClassBell.app` 拖入“应用程序”。
3. 第一次打开时按住 Control 点击应用，选择“打开”。
4. 先在 macOS 蓝牙设置里连接音箱。
5. 点击菜单栏铃铛，打开设置并选择音箱。
6. 点击某条日程旁的播放按钮试听，确认声音只来自所选音箱。
7. 打开“日程”开关；需要长期使用时再打开“登录时启动”。

## 能做什么

- 自定义时间、星期和中文说辞。
- 使用系统中文语音，或选择自己录制的音频文件。
- 先播放项目原创双音铃，间隔约半秒后播放人声。
- 默认把本次提醒音量临时设为 60%，可在 0–100% 调整；结束后恢复音箱原音量。
- 菜单栏随时启动、暂停，显示下一条提醒。
- 使用静音流降低部分蓝牙音箱在长时间无声时自动待机的概率。

## 重要限制

- 仅支持 macOS 13 及以上。
- Mac 必须开机且未进入深度睡眠。
- 音箱必须已经连接；音箱自身的省电策略无法由软件百分之百控制。
- 系统中文语音的自然度取决于 Mac 已安装的语音。可在“系统设置 → 辅助功能 → 朗读内容 → 系统语音”下载更自然的中文语音。
- 当前 GitHub 包使用临时签名，尚未经过 Apple Developer ID 公证，因此首次打开需要使用右键菜单确认。

## 从源码构建

需要 Xcode 及其命令行工具：

```bash
git clone https://github.com/stanleyhuangbs/ClassBell.git
cd ClassBell
zsh scripts/build-app.sh
```

生成文件位于 `.dist/ClassBell.app` 和 `.dist/ClassBell-1.0.0-macOS.zip`。

运行测试与隐私审计：

```bash
swift test
zsh scripts/audit-public.sh
```

## 卸载

把 `ClassBell.app` 移到废纸篓即可。源码用户也可运行 `zsh scripts/uninstall.sh`。如需连同本地日程和语音缓存一起删除，运行 `zsh scripts/uninstall.sh --purge`；脚本会先列出删除目标并要求输入 `yes`。

## 隐私与安全

ClassBell 不需要账号、不使用云端服务、不上传日程或录音。完整说明见 [Privacy.md](Privacy.md)。

本项目不会修改 macOS 默认音频输出；这是与普通日历提醒、闹钟最大的区别。
